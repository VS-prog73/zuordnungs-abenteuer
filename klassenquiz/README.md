# Zuordnungs-Arena – Klassenquiz

Interaktives Quiz für die digitale Tafel, Klasse 7. 18 neue Aufgaben zu proportionalen und antiproportionalen Zuordnungen, Wertetabellen, Fehlern und Graphen. Etwa 25–30 Minuten.

## Direkt spielen

https://zuordnungs-arena-klasse7.lithemacaw9.chatgpt.site

Öffentlich zugänglich, ohne ChatGPT-Anmeldung.

## Lokal verwenden

index.html und app.js gemeinsam in denselben Ordner herunterladen. index.html im Browser öffnen. Keine Installation, keine externen Abhängigkeiten. Auch offline verwendbar.

## Unterricht

Alle stimmen gleichzeitig mit 1, 2 oder 3 Fingern ab. Eine wechselnde Person bedient die Tafel und begründet. Anschließend Lösung aufdecken. Optional zwei bis vier Teams; Punkte werden durch die Lehrkraft vergeben. Der Timer ist optional.

## GitHub Pages

Wenn Pages für diesen Repository-Branch und den Wurzelordner aktiviert ist, liegt dieses Quiz unter dem Unterpfad /klassenquiz/. Das bestehende Lernspiel im Hauptordner bleibt erhalten.

Diese GitHub-Kopie wird nicht automatisch mit der anderen veröffentlichten Website synchronisiert.
