# Zuordnungs-Abenteuer

Lernspiel für Mathematik, Klasse 7 Hauptschule. Für iPad und andere Browser, mit zwei Niveaus, 6 Missionen und 36 Aufgaben. Geplante Lernzeit: 25–30 Minuten inklusive Rechenwegen und Reflexion.

## Spielen

https://zuordnungs-abenteuer-klasse7.lithemacaw9.chatgpt.site/

## Lokal öffnen

Alle vier Spieldateien zusammen herunterladen und index.html im Browser öffnen. Kein Build und keine Installation erforderlich. Alternativ mit einem lokalen Webserver bereitstellen.

## Dateien

- index.html: Einstieg
- app.js: Aufgaben, Spielablauf und Auswertung
- style.css: responsives Layout
- aufgaben-motive.png: Illustrationen als Bildraster

Fortschritt wird im lokalen Browser gespeichert. Keine Namen oder Schülerkonten erforderlich. Papier und Stift für Rechenwege bereitlegen.

## GitHub Pages (optional)

Unter Settings → Pages als Quelle „Deploy from a branch“, Branch „main“ und Ordner „/ (root)“ wählen. GitHub Pages ist durch diesen Upload noch nicht aktiviert.

Diese Kopie wird nicht automatisch mit der bestehenden Spielwebsite synchronisiert.
